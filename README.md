# Baxtlilar — mini app prototype (demo)

A clickable prototype of Baxtlilar, a verified, family-oriented marriage app for Uzbekistan.
Open the live demo: https://nasibulloh.github.io/baxtlilar-miniapp-demo/

- Every member, message and payment here is **fictional**. Nothing is a real person or a real transaction.
- Member and welcome photos come from [Unsplash](https://unsplash.com/license); credits are in `photos/ATTRIBUTION.md`.
- The app runs entirely in the browser and keeps its state in your browser only. `?reset` in the URL clears it.
- Uzbek is the default language; Russian and English can be picked in the app.
- This folder holds a built bundle only. The source lives in a separate private project.
